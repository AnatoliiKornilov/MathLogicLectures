# Формальные языки и сложность вычислений

### Конспект теперь разбит не по лекциям, а по тематическим блокам, которые я назвал частями.

## Содержание

1. Повторение и введение.
2. Распознавание языков на ДМТ и НМТ. Время работы. Классы DTIME и NTIME.
3. Классы P и NP, co-классы. Сводимости по Карпу и по Куку.
4. NP-трудность и NP-полнота. Существование NP-полного языка. Теорема Кука-Левина.
5. Примеры NP-полных задач.
6. Полиномиальная иерархия. Самосводимость. Задача оптимизации. Аппроксимация.
